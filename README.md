# SnowflakesK

Android-приложение на Kotlin, реализующее собственный элемент интерфейса `Snowflakes` (Custom View) вместо стандартной разметки.

## Особенности реализации
- **Пользовательский View**: в `MainActivity` разметка заменена на компонент `Snowflakes` через `setContentView(Snowflakes(this))`.
- **Замедление к нижней границе**: скорость снежинок снижается сверху вниз пропорционально `(1 - s.y / h)`.
- **Оттенки снежинок**: генерируются с помощью `Color.rgb()`.
- **Горизонтальное блуждание**: отклонение по оси X рассчитывается через функцию синуса `sin()`.
- **Фоновый поток (AsyncTask)**: класс `MoveTask` обновляет кадры анимации в фоне и передает перерисовку в UI-поток.
